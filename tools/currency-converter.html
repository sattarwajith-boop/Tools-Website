How it gets daily values

This tool fetches exchange rates from a free public API in the browser. The API returns rates using USD as the base. The tool then calculates the other three currencies from the amount you type.

For example, if you type a value in GBP, the tool first converts GBP to USD using the live GBP rate, then converts that USD value into USD, BYN and LKR.

Tip: banks, card providers and money transfer services may use different rates and fees.
