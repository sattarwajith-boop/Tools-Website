# ToolNest Studio

Static multi-tool website starter with:

- `Resume Builder`
- `Image Converter`
- `PDF Tools`
- `Text Formatter`
- `AI Prompt Helper`
- `Budget Calculator`
- `Bio Link Generator`
- theme integration with `light`, `dark`, and `system` modes
- accent switching and local draft saving

## Notes

- The PDF module uses the browser-loaded `pdf-lib` CDN script.
- Most features work fully client-side, which keeps hosting and maintenance simple.
- A good next step is splitting each tool into its own SEO landing page.
